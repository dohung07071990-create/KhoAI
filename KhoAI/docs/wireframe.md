# Wireframe giao diện Kho AI

Bản phác thảo trước khi dựng giao diện. Bố cục thực tế đã được làm responsive trong dashboard HTML/CSS.

## Camera / tổng quan

```text
┌──────────────────────┬────────────────────────────────────────────────────┐
│ KHO AI               │ Kho vận hành 01 / Camera trực tiếp      [ngày]     │
│ Kho vận hành 01      ├────────────────────────────────────────────────────┤
│                      │ Kho vận hành an toàn.             [Làm mới]       │
│ GIÁM SÁT             │ ┌────────────┐ ┌────────────┐ ┌────────────┐       │
│ ● Camera trực tiếp   │ │ Thẻ active │ │ Lượt quẹt  │ │ Bị từ chối│       │
│ ≋ Lịch sử ra vào     │ └────────────┘ └────────────┘ └────────────┘       │
│ ▤ Thẻ được cấp       │                                                    │
│                      │ CAMERA USB — YOLO       ESP32-CAM — KHO            │
│                      │ ┌──────────────────┐    ┌──────────────────┐       │
│                      │ │ hình + khung      │    │ hình trực tiếp   │       │
│                      │ │ vùng cấm          │    │ từ board         │       │
│                      │ └──────────────────┘    └──────────────────┘       │
│                      │ Lượt quẹt gần đây             Lưu ý an toàn        │
└──────────────────────┴────────────────────────────────────────────────────┘
```
